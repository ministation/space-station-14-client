## Контент и обновления

Первый запуск использует старый zip-кеш: он распаковывается в новую папку один раз, хеши файлов
сверяются с манифестом сервера, качаются только отличия.

| Проверка | Результат |
|---|---|
| Манифест сервера | 18144 файла, разбор BLAKE2B-256 |
| Переход на новый билд сервера | `Content delta: 31 changed, 0 removed of 18144` вместо 1.27 ГБ |
| Загрузка дельты | `POST /download` с `X-Robust-Download-Protocol: 1`, zstd, проверка хеша каждого файла |
| Повторный запуск | контент на месте, старт игры через 2 секунды без сети к CDN |
| Раскладка на диске | `no_backup/content_cache/content_<сервер>/`, ~1.5 ГБ, манифест и key билда рядом |

## Мобильная панель 0.7.0

Раскладка считается в `MobileControlsOverlay.ArrangeOverride`, размеры кнопок 130 / 118 / 102 логических
пикселей на `mobile.controls_scale` 1.5, стики 127 на `mobile.thumbstick_scale` 1.1, общий `fit` по короткой
стороне (0.5..1.3). Что важно знать при следующей правке:

- Каждый кластер (4 кнопки у правого стика, 5 у левого) раскладывается одним размером: сначала ищется
  наибольший общий коэффициент 1.00..0.60, при котором все кнопки кластера влезают, и только потом кластер
  ставится на экран. Поэтому внутри кластера нет разнобоя, но кластеры могут отличаться по размеру.
- Углы заданы веером (правый 100/145/190/235, левый 80/35/125/170/300), кнопка отклоняется от своего угла
  шагами по 15 градусов и уходит наружу не больше чем на 3 кольца (потом 6). Верхний предел кольца и есть
  защита от "кнопка улетела в угол экрана".
- Порядок отрисовки: панель добавлена в `RootControl` между `StateRoot` и `WindowRoot`. `ScreenRoot` сам
  встаёт на позицию 2, поэтому фактический порядок: MainViewport, StateRoot, ScreenRoot, панель, WindowRoot.
  Окна контента (WindowRoot) всегда выше панели, HUD (StateRoot) ниже.
- Безопасные поля: хост читает `DisplayCutout` и передаёт `mobile.safe_area_left/right/top/bottom` в
  физических пикселях, движок делит их на `display.uiScale` и берёт максимум с процентным полом.
- Прозрачность: `mobile.controls_opacity` по умолчанию 0.6, лаунчер даёт 0.4..0.9.
- После первого расклада панель пишет `mobile-controls-debug.txt` в файловую папку приложения: порядок
  корней, прямоугольники стиков и всех кнопок. На эмуляторе файл не появляется, потому что клиент падает
  на прототипах контента до первого кадра.

Проверка раскладки без устройства: симулятор на Python повторяет те же формулы, прогон по 55 сочетаниям
разрешений и `uiScale` (1920..3120 по ширине, ui 1.4..2.0) даёт 9/9 кнопок без наложений, коэффициент
кластера 0.85..1.0 на типичных телефонах.
