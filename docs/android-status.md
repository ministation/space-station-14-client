# Android-клиент: статус проверки

Дата: 2026-11-09. Эмулятор Android 36 (google_apis, x86_64, 1280x720, 6 ГБ ОЗУ),
APK из этого репозитория, сервер ss14.ministation.ru:1214 (билд 5387e4f5, движок 295.0.2).

## Лаунчер

Штатный экран в стиле официального лаунчера SS14: шапка SPACE STATION 14, Discord/Website/GitHub,
аккаунт, вкладки Servers/Favorites/Direct Connect, список серверов с поиском и фильтрами,
кнопка Connect, настройки, офлайн-песочница, логи, дисклеймер.

| Шаг | Результат |
|---|---|
| Установка и запуск | работает, см. `images/android-launcher.png` |
| Список серверов | 193 сервера из хаба, фильтры и поиск реагируют |
| Диалог аккаунта | открывается, поля на всю ширину, диалог прокручивается, клавиатура не перекрывает ввод |
| Прямое подключение | `--es connect_addr "host:port"` сразу запускает сервер, без ручных кликов |

## Контент и обновления

Первый запуск использует старый zip-кеш: он распаковывается в новую папку один раз, хеши файлов
сверяются с манифестом сервера, качаются только отличия.

| Проверка | Результат |
|---|---|
| Манифест сервера | 18144 файла, разбор BLAKE2B-256 |
| Переход на новый билд сервера | `Content delta: 31 changed, 0 removed of 18144` вместо 1.27 ГБ |
| Загрузка дельты | `POST /download` с `X-Robust-Download-Protocol: 1`, zstd, проверка хеша каждого файла |
| Повторный запуск | контент на месте, старт игры через 2 секунды без сети к CDN |
| Раскладка на диске | `no_backup/content_cache/content_<сервер>/`, ~1.5 ГБ, манифест и key билда рядом |
